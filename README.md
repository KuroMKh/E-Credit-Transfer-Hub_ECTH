# 🎓E-Credit Transfer Hub

The **Credit Transfer Hub** is a web-based system designed to streamline and automate the credit transfer and exemption process for higher education institutions. It benefits both students and academic staff by simplifying the evaluation of course equivalency using a text similarity algorithm.

## 🚀 Features

- 🔐 Student,Admin, and Subject Matter Expert (SME) Login
- 📄 Online Credit Transfer Application Submission
- 📚 Automated Course Similarity Comparison using **Jaro-Winkler Distance**
- 📊 Application Status Tracking
- 🗃️ Admin Panel for Evaluating and Managing Applications
- 📥 File Upload Support for Transcripts and Syllabi
- 🔍 Integrated with **spaCy** and **Datamuse API** for text processing

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, Bootstrap, JavaScript
- **Backend**: PHP (procedural), MySQL
- **API Connector**: Flask (Python)
- **Text Similarity**: Python with spaCy, Datamuse, and Jaro-Winkler
- **Tools**: XAMPP, phpMyAdmin, Visual Studio Code
